## 목표 동작

정상적인 양발 서기에서 시작해 다리를 굽혀 이륙하고, 양발이 공중에 있는 동안 수직축(world Z)을 중심으로 360° 회전한 뒤 양발로 착지해 안정적인 HOME 자세로 돌아오는 동작입니다.

- Task ID: `Mjlab-JumpSpin-Flat-MicroDuck`
- 현재 실험 이름: `jump_spin_launch_v2`
- 정책 입력 61차원, 관절 출력 14차원
- 체크포인트 저장 간격: 100 PPO iterations

발을 땅에 둔 채 도는 동작이나 몸을 앞뒤로 구르는 동작은 목표가 아닙니다. 최종 목표는 실제 로봇 적용이지만, 현재는 시뮬레이션 학습과 검증 단계입니다.

## 자동 커리큘럼

| PPO iteration | 회전 목표 |
|---|---|
| 0–1499 | 180° |
| 1500–3999 | 270° |
| 4000 이후 | 360° |

초기에는 공중·착지에 가까운 상태에서 시작하는 에피소드를 섞어 동작의 뒷부분도 경험하게 합니다. 이후 정상 서기에서 시작하는 비율을 높입니다. 이 변화는 한 번의 학습 안에서 자동으로 진행됩니다. 사용자가 단계마다 셀을 다시 실행할 필요는 없습니다.

학습 횟수가 늘었다고 성공을 보장하지는 않습니다. 실제 동작이 목표를 만족하는지는 [영상과 진단](evaluation.md)으로 확인합니다.

## 주요 보상과 관찰 항목

| 항목 | 확인할 내용 |
|---|---|
| `jump_launch` | 상승과 이륙 시도를 배우는가 |
| `jump_height` | 충분히 높이 상승하는가 |
| `jump_spin_progress` | 양발이 공중인 동안 회전이 진행되는가 |
| `jump_airborne_upright` | 공중에서 수직축 회전 자세를 유지하는가 |
| `jump_landing` | 목표 회전에 가까운 상태에서 양발 HOME 착지를 하는가 |
| `jump_heading_return` | 360° 단계에서 출발 방향으로 돌아오는가 |
| `jump_wrong_axis` | 앞뒤·좌우 구르기가 억제되는가 |
| `jump_horizontal_drift` | 제자리에서 크게 벗어나지 않는가 |
| `jump_landing_impact` | 착지 충격이 과도하지 않은가 |

`Episode_Reward/<항목>`은 가중치가 적용된 값입니다. 가중치가 0인 단계에서는 동작이 있어도 값이 0일 수 있습니다. 총 보상만 보지 말고 현재 커리큘럼과 주 동작 항목을 함께 봅니다. 페널티의 기록값은 0 이하여야 합니다.

## 기존 실패 분석과 launch v2

2026-10-08 제공된 이전 `model_9999.pt` 평가 요약에서는 5회 모두 225스텝(4.5초)을 실행했지만 관측 회전량이 0°였습니다. 제공된 로그의 마지막 100회 평균은 `jump_launch=0.00076`, `jump_spin_progress=0.06979`, `action_rate_l2=-0.94698`이었습니다. 로그가 초기 0–12회와 마지막 9100–9999회에 한정돼 전체 학습 경과는 복원할 수 없었습니다.

v2에서 수정한 내용은 다음과 같습니다.

- 기존 이륙 보상의 `vertical * yaw`는 회전 없는 상승에 0을 반환했습니다. v2는 상승 자체에도 신호를 주고 회전이 동반되면 추가 점수를 줍니다. 에피소드 내 이전 최고 점수를 넘은 증가분만 지급해 반복 동작으로 보상을 계속 얻지 못하게 했습니다. `step_dt` 적분 후 최대 지급량은 보상 가중치 이하입니다.
- 착지 보조 시작의 300–355° 범위는 초기 180°·270° 목표를 이미 넘었습니다. v2는 진행량을 현재 목표에 비례시킵니다. 180° 단계는 150–177.5°, 270° 단계는 225–266.25°, 360° 단계는 기존 범위입니다.

이전 `jump_spin` 체크포인트는 보존하고 새 `jump_spin_launch_v2` 실험에 자동으로 이어받지 않습니다. 보상 코드 변경만으로 기존 모델의 가중치가 개선되지는 않습니다.

v2는 Colab A100에서 설정·MDP·진단 검사, 64개 환경·5회 학습, 공식 ONNX 내보내기와 61→14 추론 검증을 통과했습니다. 이는 실행 경로 검증이며, 최종 360° 동작 성공은 완료된 모델의 반복 평가로 별도 확인해야 합니다.
